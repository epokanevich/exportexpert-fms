# Changelog

## [0.2.0] — 2026-10-27 — подготовка к боевому учёту SOC

Не задеплоено. Перед выкаткой — [docs/DEPLOY.md](docs/DEPLOY.md) (pre-flight, `DEMO_MODE=true` для демо-стенда).

### ⚠ Изменения, требующие действий
- **Демо-режим выключен по умолчанию.** Демо-стенду нужна переменная `DEMO_MODE=true`.
- **Миграции вместо `db push`.** Сборка: `npm run render-build` (baseline `0_init` для существующей базы делается автоматически).
- **Все текущие сессии потребуют повторного входа** (в JWT добавлена версия сессии).
- **Пустая боевая база** создаётся только с `ADMIN_INITIAL_PASSWORD` (демо-данные — только при `DEMO_MODE=true`).
- Демо-префикс `EXEX` → `EXPU` (ISO 6346, категория U): после «Сбросить демо-данные» номера демо-контейнеров изменятся.

### Деньги и целостность данных
- Деньги — `numeric(12,2)`, арифметика в центах, единое округление (`src/lib/money.ts`) — D-29.
- История ставок аренды `LeaseRatePeriod`: продление с новой ставкой, прошлые дни не пересчитываются — D-08.
- Мягкое списание (WRITTEN_OFF + `deletedAt` + причина), фильтр «Списанные»; CASCADE → RESTRICT.
- Частичные уникальные индексы «одна активная операция на контейнер», CHECK на статусы, роли и суммы; роль по умолчанию INSPECTOR — D-30.
- Нарушения ограничений БД — понятные русские сообщения вместо 500.

### Бизнес-логика
- Договор с будущим On-Hire — статус «Ожидает On-Hire», контейнеры в резерве, не в «аренде» и не в $/мес — D-19.
- Конвенция Free Time — одна константа `FREE_TIME_CONVENTION` (по умолчанию прежняя), тесты на обе — D-20.
- Тех. статус, грейд, EOR и срок КБК меняются только актом осмотра / продлением КБК — D-21.
- Бизнес-часовой пояс `BUSINESS_TIMEZONE` (Europe/Moscow) для «сегодня», просрочек и дашборда — D-28, D-06.
- Номер таблички CSC, программа ACEP/PES, собственник/лизингодатель; строки повреждений CEDEX в акте осмотра.
- Вложения PNG/JPEG/PDF ≤ 5 МБ к событиям журнала, тип по сигнатуре, хранилище `local` | `db`.

### Безопасность
- Отзыв сессий через `User.tokenVersion` (выход, смена роли и пароля) — D-10.
- Лимит входа в PostgreSQL, атомарный, по IP + email; владелец с другого IP не блокируется — D-09.
- Смена пароля в профиле; пользователи и роли для ADMIN; политика паролей ≥ 10 символов.
- CSP с nonce (без `unsafe-inline`/`unsafe-eval` для скриптов), HSTS, `frame-ancestors 'none'` — D-25.
- Аудит-журнал всех мутаций в той же транзакции, просмотр для ADMIN.
- `npm audit`: 0 уязвимостей (override `deepmerge-ts` ^8 вместо мажорного обновления Prisma).

### UX и доступность
- Реестр: серверный поиск (pg_trgm), пагинация, сортировка по всей выборке, CSV всей выборки — до тысяч единиц.
- Тап-цели ≥ 44 px на телефоне и планшете — D-17; строки таблиц доступны с клавиатуры — D-22.
- Сообщения валидации на русском; у полей форм есть id/name; контраст текста ≥ 4.5:1 (Lighthouse A11y 100).
- Денежные поля принимают центы (`step="0.01"`).

### Исправлено по ревью и браузерной проверке
- Параллельный Off-Hire разных единиц мог оставить договор ACTIVE навсегда; продление могло изменить закрытый договор.
- Пачка одновременных попыток входа обходила лимит.
- Gate-In / Gate-Out без захвата по статусу (гонка с выдачей).
- Пустое необязательное денежное поле превращалось в $0.
- Zod 4 нарушал CSP проверкой `new Function`; proxy перезаписывал CSP ответов `/api/*`.
