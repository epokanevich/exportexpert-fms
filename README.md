# FMS «Экспортэксперт» — управление парком собственных контейнеров (SOC)

Промышленное MVP Fleet Management System: реестр парка с проверкой номеров по ISO 6346, контроль One-Way
(репозиционирование с расчётом детеншна), долгосрочная аренда с начислениями Per Diem, терминальный
инспектор для работы со смартфона и дашборд руководителя.

Архитектура и доменная модель: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт

Требуется Node.js 20.9+ и PostgreSQL 14+ (облачный [Neon](https://neon.tech), Vercel Postgres или локальный).

```bash
npm install
cp .env.example .env      # укажите DATABASE_URL (PostgreSQL) и AUTH_SECRET (≥ 32 символов)
npm run setup             # prisma db push + prisma db seed: схема и демо-данные
npm run dev               # http://localhost:3000
```

Вход: `admin@exportexpert.ru` / `Export2026!` — форма предзаполнена, есть кнопка
**«Быстрый демо-вход в 1 клик»**. Кнопка **«Сбросить демо-данные к исходным»** — в профиле
(сайдбар на ПК, аватар в шапке на телефоне).

| Команда | Что делает |
|---|---|
| `npm run dev` | Dev-сервер |
| `npm run build` / `npm start` | Production-сборка и запуск |
| `npm run typecheck` | Проверка типов |
| `npm test` | Unit-тесты доменной логики (Vitest) |
| `npm run db:push` | Применить схему `prisma/schema.prisma` к базе |
| `npm run db:seed` | Перезалить демо-данные (`prisma db seed`, очищает доменные таблицы) |
| `npm run db:bootstrap` | Залить демо-данные, **только если база пустая** (используется при деплое) |

## Что показать проверяющему (демо-сценарии)

Все даты в демо-данных считаются от текущего дня, поэтому сценарии актуальны при любом запуске.

- **Дашборд** — 31 контейнер / 50 TEU, утилизация, горящие и просроченные One-Way, доход аренды $/мес,
  алерты (КБК, ремонт, простой), распределение по регионам и статусам.
- **Контроль One-Way** — 8 активных рейсов: 2 просрочены (EXEX 402918, FESU 518204 — детеншн капает),
  у 2 дедлайн через 2–3 дня; одна открытая претензия (FESU 516877). Gate-In в 1 клик с выбором состояния
  при приёмке и предпросмотром детеншна; при повреждении открывается претензия (DISPUTE).
- **Долгосрочная аренда** — 4 действующих договора (10 ед.): LC-2026/003 «Балтика Фрейт» истекает через 10 дней,
  LC-2026/007 «Восток-Транзит» — задолженность. Калькулятор начислений, продление, Off-Hire только в разрешённые регионы.
- **Реестр** — поиск по подстроке номера (`2918`), мультифильтры, сортировка, Slide-over быстрого просмотра,
  добавление контейнера с живой проверкой контрольной цифры ISO 6346 (кнопка «Подставить» исправляет цифру).
- **Профиль контейнера** — паспорт, техсостояние и КБК, дислокация и стоимость простоя, экономика (ROI),
  коммерческая история и полный журнал событий.
- **Терминальный инспектор** — откройте на телефоне (или эмуляции 375px): найдите `9930` (RZDU 769930 в ремонте),
  нажмите «Исправен» — ремонт закроется, EOR уйдёт в затраты, контейнер вернётся на сток.
- **Блокировка по КБК (CSC)** — EXEX 401890-8 исправен, но табличка просрочена: в формах выдачи One-Way и аренды
  он виден, но недоступен с причиной; сервер отклоняет выдачу даже при подделанном запросе.
- **Гид для проверяющего** на `/login` — 5 отраслевых фишек, каждая кнопка выполняет демо-вход сразу на нужный экран.

## Инструменты логиста

- **Выгрузка в Excel (CSV)** — кнопка «Excel / CSV» в реестре, One-Way и аренде выгружает текущую отфильтрованную
  выборку: UTF-8 с BOM, разделитель `;`, десятичная запятая, даты `дд.мм.гггг` — файл сразу открывается в русском Excel.
  Ячейки, начинающиеся с `= + - @`, нейтрализуются (защита от CSV-инъекций), телефоны выгружаются чистым текстом.
- **Release Order / памятка на возврат** — иконка принтера в строке рейса One-Way (или «Релиз / Памятка» в карточке)
  открывает документ A4: BIC, типоразмер, контрагент, терминал выдачи и обязательного возврата (Drop-off),
  свободные дни, Free Time Deadline, ставка детеншна с примерами начисления, условия возврата и поля подписей.
  Кнопка «Печать / PDF» вызывает `window.print()`; служебные элементы при печати скрываются.

## Бизнес-правила (выдержка)

- Номер контейнера: 4 буквы + 6 цифр + контрольная цифра по ISO 6346 (веса 2^i, буквы 10–38 без кратных 11).
- `deadline = handoverDate + freeDays`; детеншн = дни просрочки × ставка; OVERDUE вычисляется, а не хранится.
- Выдача (One-Way, аренда, Gate-Out) запрещена, если контейнер не исправен или просрочена табличка КБК (CSC).
- Начисления аренды: дни On-Hire … накануне Off-Hire × Per Diem по каждой единице.
- ROI единицы = (выручка − ремонты − амортизация) / цена покупки.

## База данных: PostgreSQL (Neon)

- Провайдер Prisma — `postgresql`; строка подключения только в переменной `DATABASE_URL`
  (локально — `.env`, в облаке — переменные окружения Vercel). В репозиторий попадает лишь шаблон `.env.example`.
- Для Neon используйте **pooled**-хост (`…-pooler…`) и `sslmode=require` — так serverless-функции Vercel
  не исчерпывают лимит соединений.
- Демо-сид пишет данные пакетно (≈12 запросов в одной транзакции, ~2 с), поэтому «Сбросить демо-данные»
  укладывается в лимит serverless-функции (`maxDuration = 60`).
- Схема совместима и с SQLite: для полностью офлайн-демо достаточно вернуть `provider = "sqlite"` и
  `DATABASE_URL="file:./dev.db"`.

## Деплой на Vercel

1. Создайте базу в Neon (Connect → Prisma → pooled connection string).
2. Импортируйте репозиторий в Vercel (Framework: Next.js — определяется автоматически).
3. В **Settings → Environment Variables** задайте для Production (и Preview, если нужно):
   - `DATABASE_URL` — строка Neon вида `postgresql://user:password@host/dbname?sslmode=require`;
   - `AUTH_SECRET` — случайная строка ≥ 32 символов
     (`node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"`).
4. Deploy. Vercel вызывает скрипт `vercel-build`:
   `prisma generate → prisma db push → prisma/bootstrap.ts → next build`.
   Схема применяется автоматически; демо-данные загружаются **только в пустую базу**, повторные деплои
   рабочие данные не затирают. `prisma db push` без `--accept-data-loss` остановит деплой, если изменение
   схемы грозит потерей данных.
5. Откройте сайт → «Быстрый демо-вход в 1 клик».

> **Сетевое ограничение.** Из некоторых сетей TLS-соединения с облачными хостингами (AWS, где работает Neon)
> обрываются после первых ~10–16 КБ трафика: подключение устанавливается, но `prisma db push`, сид и любые
> «тяжёлые» запросы зависают или завершаются `P1017: Server has closed the connection`. Это не ошибка приложения.
> В таком случае выполняйте `npm run setup` из другой сети (CI, сервер, VPN) или просто задеплойте проект —
> начальная загрузка выполнится на стороне Vercel.

### Замечания для продакшена

- Ограничитель попыток входа хранится в памяти инстанса; при нескольких serverless-инстансах нужен общий
  стор (Redis / Upstash).
- Для эволюции схемы с историей изменений перейдите с `db push` на `prisma migrate` (`migrate dev` локально,
  `migrate deploy` в `vercel-build`).
