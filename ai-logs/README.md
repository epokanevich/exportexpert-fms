# Оригиналы переписки с ИИ (Claude Code)

Три файла — три переписки, из которых собран [AI_CONVERSATION_LOG.md](../AI_CONVERSATION_LOG.md) (части 1–3).
Формат — JSONL, одна запись на реплику, вызов инструмента или его результат, без изменений текста.

| Файл | Часть в AI_CONVERSATION_LOG.md | Период (UTC) |
|---|---|---|
| `part1-development.jsonl` | Часть 1. Разработка приложения FMS | 26.10.2026 |
| `part2-acceptance.jsonl` | Часть 2. Приёмка и боевая проверка | 26–27.10.2026 |
| `part3-round2.jsonl` | Часть 3. Доводка до боевого учёта (раунд 2) | 27.10.2026 |

Что убрано из выгрузки (это служебные данные Claude Code, не реплики): тела запросов к API (`api-request*`, включая
системные промпты), вывод хуков и вложения (`attachment`), метки сессии и снимки файлов. Единственная правка в тексте —
личный адрес почты автора заменён на `[email]`.
