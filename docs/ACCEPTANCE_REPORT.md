## 4. Что НЕ проверено и почему

- **Прод (Render, Neon)** — по правилам задания не трогался; pre-flight по боевым данным не выполнен — нужен запуск владельцем.
- **chrome-devtools-mcp** трижды зависал на 30 минут. Браузерная часть сделана во встроенном браузере Claude, Lighthouse CLI и
  puppeteer-core с тем же Chrome. Сценарии вводились программно (заполнение полей и отправка формы), а не реальными касаниями.
- **Реальные устройства, Safari, Firefox, VoiceOver/TalkBack** — только Chromium с эмуляцией.
- **Нагрузка с параллельными пользователями** — проверены только объём (5 000 единиц) и гонки; нагрузочного теста RPS нет.
- **Vercel** — тело функции ограничено 4,5 МБ: загрузку 5 МБ на Vercel не проверял. Целевая платформа — Render.
- Сценарий из одного раунда не воспроизвёлся: однократный переход страницы на `/` после Off-Hire (повтор — без перехода; в коде переходов нет).
- `/admin` для не-админа отдаёт страницу «не найдено» со статусом 200 (особенность стриминга Next.js), а не 404.

## 5. Остаточные риски и чего не хватает до полной эксплуатации

- **EDI CODECO/COPARN**, интеграции с терминалами и линиями; **счета и акты**, валюты, НДС; holdover-ставки, DPP, pick-up/drop-off fees.
- **Вложения**: драйвер S3 / Vercel Blob (private) не написан (на Render работает `db`); нет антивируса и миниатюр.
- **Справочник CEDEX** — подсказки с распространёнными кодами; полный справочник сверить с M&R-подрядчиком. Согласование EOR (workflow) не реализовано.
- Дашборд считает KPI по всему парку в памяти: при 5 000 единиц — 308 мс. При десятках тысяч нужна агрегация в SQL.
- Ленивая активация SCHEDULED-договоров выполняется при рендере защищённой зоны; если месяц никто не заходит, статус догонится при первом входе.
- Индексы под фильтр «внимания» (`cscPlateExpiry`, `techStatus`) не добавлены — при 5 000 единиц не нужны (60 мс).
- Мажорные обновления не выполнялись: Prisma 7/8, TypeScript 7, @types/node 26. Минорное — lucide-react 1.62.
- Нет ESLint-конфигурации (замечание typescript-reviewer) — `react-hooks/exhaustive-deps` не проверяется автоматически.
